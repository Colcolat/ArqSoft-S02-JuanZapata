# Juego de Ahorcado (Hangman) 

##  Descripción del Proyecto
Este proyecto es una implementación del clásico juego del "Ahorcado" desarrollada como una aplicación de consola. El objetivo del juego es adivinar una palabra secreta relacionada con la ingeniería de software (como "arquitectura", "polimorfismo", "encapsulamiento", etc.) ingresando letra por letra antes de agotar los 6 intentos permitidos.

El diseño del proyecto destaca la separación de responsabilidades y buenas prácticas de arquitectura, dividiendo el sistema en:
* **Lógica del Juego:** Administrada a través del motor del juego que evalúa condiciones de victoria o derrota.
* **Interfaz de Usuario:** Manejo de la consola y dibujo de los estados del ahorcado de manera separada.
* **Datos:** Repositorio en memoria para proveer las palabras secretas de la partida.

##  Tecnologías Usadas
* **Lenguaje:** C#
* **Framework:** .NET 10.0
* **Tipo de Proyecto:** Aplicación de Consola
* **Paradigma:** Programación Orientada a Objetos (POO)

##  Cómo ejecutar el proyecto

Para correr esta aplicación necesitas tener instalado el [SDK de .NET 10.0](https://dotnet.microsoft.com/download/dotnet/10.0).

1. Abre tu terminal o consola de comandos.
2. Navega hasta la carpeta raíz del proyecto (donde se encuentra el archivo `Ahorcado.csproj`).
3. Ejecuta el siguiente comando:

\`\`\`bash
dotnet run
